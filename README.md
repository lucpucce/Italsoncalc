# 📉 Simulazione Demografica: Stabilizzazione della Popolazione Italiana

Un simulatore demografico interattivo e autocontenuto in un unico file HTML. Il progetto permette di esplorare visivamente gli scenari futuri della popolazione italiana da qui al 2100, analizzando l'impatto del tasso di fertilità e dei flussi migratori. Non è un vero calcolo probabilistico ma deterministico.
